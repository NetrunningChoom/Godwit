# Network glyphs

Original geometric chat glyphs, AGPL-3.0-only like Godwit. These are generic
identifiers for Godwit's network views, not the networks' logos. Google Chat
uses a plain speech bubble; no Google logo or Google brand artwork is included.
Discord is headphones, Steam a gamepad and Stoat a paw print: generic symbols
for each network's theme (voice, games, the animal), not their logos.
